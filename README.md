# SmartBiz Analytics
### Automated Business Intelligence & Prediction Platform

SmartBiz Analytics is a Python-based business intelligence application built with Streamlit. It helps users analyze business data, discover patterns, identify anomalies, and generate actionable insights.

## Features

- Upload CSV and Excel files
- Automated data profiling and quality checks
- Data cleaning and business metrics
- Interactive data visualizations
- Anomaly detection
- Machine learning predictions
- Forecasting and segmentation
- Automated insights and recommendations
- Root cause analysis
- Ask Your Data
- Business reports and exports

## Technology Stack

- Python
- Pandas and NumPy
- Streamlit
- Plotly
- Machine Learning
- Git and GitHub

## Run the Project Locally

1. Clone this repository.
2. Open the project folder in VS Code.
3. Create and activate a Python virtual environment.
4. Install dependencies:

   `python -m pip install -r requirements.txt`

5. Run the application:

   `python -m streamlit run app.py`

## Project Goal

The goal of SmartBiz Analytics is to bring data quality checks, business analytics, visualization, prediction, and reporting into one application.
